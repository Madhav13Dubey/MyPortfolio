Featured work · Truvis.ai

Text-to-SQL, in plain English

Built at Truvis.ai

Natural language to SQL, powered by RAG

While working at Truvis.ai I built a tool that turns everyday questions into SQL queries. It uses retrieval-augmented generation (RAG) to ground the model, runs on a free open-source LLM from Hugging Face, and switches to a paid OpenAI key automatically when the Hugging Face limit is reached — so it stays cost-aware without going down.

  • Ask, don't write Non-technical teammates query data by just asking.
  • RAG-grounded Relevant context is retrieved first, so answers stay tied to the data.
  • Free first, paid as backup Open-source Hugging Face by default; OpenAI only when needed.
  • RAG
  • LLM
  • Hugging Face
  • OpenAI API
  • Text-to-SQL
  • Vector DB
  • SQL guardrails
  1. 1
    Ask in plain English "Which customers placed the most orders last month?"
  2. 2
    RAG retrieval Finds the relevant context for the question.
  3. 3
    Open-source LLM Hugging Face model generates the query (free).
  4. ↻
    Automatic fallback Hugging Face limit reached? Switches to the OpenAI API (paid).
  5. 4
    SQL, ready to run The generated query is returned to the user.
